# Security policy

## Supported versions

Security fixes are provided for the latest Marketplace version. Pre-release
builds are evaluation software and should not be used where stability is
required.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for
`ivan-gromov-dev/gopdsdk-vscode`. Do not disclose exploitable details in a public
issue. Include affected versions, reproduction steps, impact, and any proposed
mitigation. If private reporting is unavailable, open a public issue containing
only a request for a private contact channel.
