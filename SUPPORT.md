# Support

Use [GitHub Issues](https://github.com/ivan-gromov-dev/gopdsdk-vscode/issues)
for reproducible extension defects and feature requests. Include the operating
system, VS Code version, extension version, `gopdsdk` version, analyzer protocol,
and redacted output-channel messages.

Do not include source code, access tokens, private paths, environment variables,
or unredacted logs. Questions about analyzer rules or CLI behavior belong in the
main [gopdsdk repository](https://github.com/ivan-gromov-dev/gopdsdk).

This community project has no guaranteed response time or commercial support
commitment. Security reports should follow [SECURITY.md](SECURITY.md).
